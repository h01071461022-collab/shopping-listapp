# 🛒 쇼핑 리스트 앱

간단하고 사용하기 쉬운 쇼핑 리스트 웹 애플리케이션입니다.

## 기능

- ✅ 쇼핑 항목 추가 및 삭제
- ✅ 항목 완료 상태 표시 (체크박스)
- ✅ 완료한 항목 자동 스타일링
- ✅ 로컬 스토리지에 자동 저장
- ✅ 반응형 디자인
- ✅ 통계 정보 표시 (총 항목 수, 완료 항목 수)

## 사용 방법

1. `shopping-list.html` 파일을 브라우저에서 엽니다
2. 입력 필드에 구매할 물건을 입력합니다
3. "추가" 버튼을 클릭하거나 Enter 키를 누릅니다
4. 완료한 항목은 체크박스를 클릭하여 표시합니다
5. "삭제" 버튼을 클릭하여 항목을 제거합니다

## 기술 스택

- HTML5
- CSS3 (Gradient, Flexbox, Transition)
- Vanilla JavaScript
- LocalStorage API
